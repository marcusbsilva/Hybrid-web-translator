# Expanded dictionary pack — 6.0.0

This pack contains eight native source dictionaries and nine destination bilingual indexes, source manifests, dataset licenses/credits, GPL source archives and regeneration tools.

Use the full Hybrid-web-translator 6.0.0 extension for the new local bilingual functionality. Copying these files into an older extension will not install the necessary engine/worker loader. Unpack this pack into a 6.0.0 project, preserving its dictionaries/, tools/, docs/ and third_party/ paths, then reload the extension and existing pages once. Language changes afterward do not require page reloads or enabling fallback.

668,467 native reference keys; 1,565,611 directional bilingual entries including aliases. Counts are not guaranteed sentence coverage. Vietnamese/Thai rely more heavily on English pivots. Unknown ordinary spans can remain untranslated while known phrases are retained. Filename validation remains strict. Curated/custom UI meanings take priority; imported senses can be ambiguous.

See tools/README.md for rebuilding sources. See THIRD_PARTY_NOTICES.md and third_party/freedict/ for the applicable licenses. Original software is MIT; dataset licenses remain CC BY-SA or GPL as specified per source.
