Local dictionary is always used first. Google is called only for unresolved/low-confidence text, in batches, and each result is learned locally so the same source text does not need another API call.
The installed extension package cannot rewrite its own JS dictionary files at runtime. Learned entries are persisted in Chrome extension storage and can be exported as JSON for permanent merging.
